## 📖 About the Project

**Gujarat Tourism** is a modern and interactive tourism website designed to showcase the beauty, heritage, culture, food, architecture, wildlife, and famous destinations of Gujarat, India.

The project focuses on creating an engaging digital travel experience where users can explore Gujarat's iconic destinations and learn more about the state's rich history and cultural identity.

The application is built using a modern **Vite + TypeScript** frontend architecture and is deployed using **GitHub Pages**.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Ankitraj-sharma/Gujarat_tourism.git
```

### 2. Navigate into the project

```bash
cd Gujarat_tourism
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the Gemini API

Create a `.env.local` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

> ⚠️ Never commit your real API key to GitHub.

### 5. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

---

## 🏗️ Build for Production

Create an optimized production build using:

```bash
npm run build
```

The generated production files will be available inside:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```
